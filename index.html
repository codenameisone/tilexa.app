If you used Launchpad, you already know Tilexa.

Type
Start typing as soon as the grid opens. Return opens the first match.
Drag
Drop one app on another to make a folder.
Hold ⌥
The icons jiggle. Move them around, or click × to send an app to the Trash.
Swipe
Two fingers on the trackpad turn the page. The arrow keys do too.
Esc
Closes it. So does clicking an empty spot or switching desktops.
